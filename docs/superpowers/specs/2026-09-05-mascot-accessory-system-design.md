## 0. 一句话

给 16 型各配一只**同一基础型 + 不同配件**的小怪物立绘，替换掉现在每次随机生成的插画，
让「我是哪一只」成为分享动力，同时把卡片从"整图现生"变成"预制立绘 + 模板合成"，顺手消灭数字画错的问题。

三体的比喻：这只小东西是 AI 人事部提前派到你电脑里的**质子**——它长成什么样，取决于你怎么堆文件。

## 2. 核心：四轴 → 四槽位 → 八配件（属性对应表）

设计原则（每个配件都要过这四条）：

1. **不遮眼**。眼神是基础型的灵魂，任何配件不得盖住瞳孔；嘴部的两颗小尖牙也要保留可见。
2. **300px 缩略图可辨**。两态之间的差异靠**剪影**就能分出来，不靠细节和颜色。
3. **语义直白**。看图就能猜到它在说"整齐/乱""造/囤""稳/爆""老/轻"，不需要解释。
4. **可实体化**。每个配件在想象中都能做成磁吸件或外套，不依赖表情肌肉变化（Body 02 的脸是固定的）。

| 轴 | 槽位 | 态 | 配件 | 视觉说明 |
|---|---|---|---|---|
| **结构 R/C** | 头顶 | **R 规整** | 索引标签 | 头顶端正插着一枚文件夹式的索引标签卡（tab），像被归档过的人 |
| | | **C 混沌** | 炸毛便利贴 | 头顶一撮炸开的乱发，黏着两三张歪斜便利贴和一截线团 |
| **产出 M/K** | 手部 | **M 造** | 巨型铅笔 | 一只举起的手握着一支跟身体差不多长的铅笔（或扳手），另一手照常举着 |
| | | **K 囤** | 封条纸箱 | 胸前抱着一个贴满封条与"易碎"标签的纸箱，双手扶箱 |
| **节奏 S/B** | 面部（情绪面具线） | **S 稳定** | 圆框眼镜 | 一副细圆框眼镜，镜片透明，眼睛清晰可见；日常、沉稳 |
| | | **B 突发** | 引信 + 黑眼圈 | 嘴角咬着一根冒火花的短引信，眼下两道黑眼圈；随时要炸 |
| **时间 A/F** | 背部 / 脚边 | **A 考古** | 蛛网档案箱 | 背上驮着两三个叠放的旧档案箱，落灰、一角挂蛛网，像龟壳 |
| | | **F 轻装** | 迷你拉杆箱 | 脚边立着一只小拉杆箱，手柄拉起，随时要走 |

配色规范：
- 身体保持**哑光白模**，不上色，不改比例。
- 配件主色 **炭灰 #2b2f3a**，点缀 **金黄 #ffd166**（与卡片主色一致）。
- **稀有型（★）配件整体换成金黄 #ffd166**，其余不变——稀有靠"金件"一眼识别。

背景：直接生成在卡片深色底 **#14161f** 上，1:1，这样立绘可以不抠图直接落进卡片。

## 5. 生成流程（执行 agent 照此跑，两道人工闸门）

工具：`~/.claude/skills/nano-banana-pro/scripts/`（`--model pro --resolution 2K --aspect-ratio 1:1`），
**每一张都用 `--input-image base-body-02.png` 作参考**，这是一致性的唯一锁。

### 固定描述块（每个 prompt 开头原样复制，不改字）

> 同一只角色，严格保持参考图的形体、比例、材质与表情：哑光白色搪胶质感的圆润小怪物，
> 两只圆眼黑瞳带高光，微笑嘴角露出两颗小圆尖牙，两只短臂举起，坐姿。
> 不改变身体颜色，不改变脸部，不添加任何文字。深色纯色背景 #14161f，柔光棚拍，正面略俯视，居中，留边 10%。
> 配件材质为哑光炭灰 #2b2f3a 硬质塑料，点缀金黄 #ffd166。

### 阶段一：定八个配件（4 张对比图）

每张一个轴，画面左右并排同一只角色，左边挂"前态"配件、右边挂"后态"配件，其余槽位**全空**。
目的：先把 8 个配件的造型钉死，再组合，避免 16 张里同一配件长得不一样。

每张最多重试 3 次。验收人：贾老师。
验收项：剪影可辨 / 不遮眼 / 语义直白 / 白模未被上色 / 无文字。

**闸门 1：4 张对比图全部验收通过，才进阶段二。** 如果某个配件三次都出不来，回到本文档第 2 节改配件定义，不硬凑。

### 阶段二：16 张成品

按第 3 节组合表，每张 prompt = 固定描述块 + 四个槽位的配件描述（从第 2 节逐字复制）+ 稀有型加一句
"所有配件改为金黄 #ffd166 哑光材质"。

建议顺序：先出 4 个稀有型（它们要金件，最容易暴露风格漂移），再出其余 12 张。

每张最多重试 3 次，超过则记入 MANIFEST 并跳过，最后统一处理。

**闸门 2：16 张并排看一遍（做一张 4×4 拼图），贾老师确认"是同一只"。**

### 阶段三：接入卡片

改 `plugins/ai-hr/SKILL.md` Step 5 / Step 6，两条路线，**先上 3a，3b 视环境探测结果决定**：

- **3a 参考图路线（零新依赖，立即可上）**：Step 5 生成整卡时，把 `assets/mascots/<型号>.png` 作为
  `--input-image` 参考，prompt 里"中间一张扁平插画"改成"中间放参考图中的这只角色，保持一致"。
  角色一致性问题解决；数字核对流程保留不变。
- **3b 模板合成路线（彻底解决数字准确性）**：card.html 的 `{{IMAGE_SRC}}` 填对应 PNG，
  其余占位符填文本，再把 HTML 渲成 PNG。**前提是 WorkBuddy 运行环境能做 HTML→PNG**（headless Chrome / Playwright）。
  执行 agent 需先在 WorkBuddy 里探测这一点并把结果写回本文档第 7 节，再决定是否实施。

无论哪条路线，Step 7 交付文案追加一句：「这是你的质子 · 【角色名】」，并说明"16 只里你抽到的是哪一只"。

## 6. 验收标准（整体）

- [ ] 任选一张，300px 缩略图下四个槽位的态都能辨认
- [ ] 四张稀有型金件明显，且互相不撞脸
- [ ] 所有图无文字、无水印、白模未被上色、眼睛与尖牙可见
- [ ] MANIFEST.md 记录每张的最终 prompt
